# StagePilot — Smart Anchor & Stage Flow (GDGPS)

Interactive event-operations prototype for Bit N Build ’26. Review disruption impact, approve a revised run-of-show, and generate updated anchor cues and team briefing.

## Live demo
https://stagepilot-smart-anchor-gdgps.vercel.app

## Demo flow
1. Simulate a speaker delay or enter a custom delay.
2. Review the proposed schedule impact.
3. Approve the revised plan to update the run-of-show, anchor cue, and team briefing.
4. Export the schedule or download/copy the briefing.

## Run locally
Open `index.html` in a modern browser. No build step or API key required.

## Prototype limitations
Uses seeded event data and deterministic browser-side rules. No live LLM, venue integration, or external messages. Organizer approval is required before applying changes.
